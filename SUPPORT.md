# Support

Start with [Getting started](docs/getting-started.md) for local use and [Deployment](docs/deployment.md) for Node and PostgreSQL. The [documentation index](docs/README.md) routes to behavior and data contracts; the [runbooks](docs/runbooks/README.md) cover repeatable maintenance and recovery.

For a question or reproducible bug, use this repository's Issues tab. Include the revision, Node/browser version, selected view and a few steps using the bundled examples. State what you expected and what happened. A short sanitized error description is usually enough to begin; keep credentials, cookies, real records and private hosting logs with their owners.

This is a solo-maintained example project. The maintainer can discuss a repair or contribution, while availability and response time vary. Hosting account access, DNS and provider service failures remain with the deployment operator and provider. A GitHub check or local build cannot establish the health of a separately deployed instance.

Use [Security](SECURITY.md) for a sensitive finding and [Contributing](CONTRIBUTING.md) to propose a change. Repository discussions follow the [conduct policy](CODE_OF_CONDUCT.md).
